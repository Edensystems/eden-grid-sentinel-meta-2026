# Milestone Acceptance Gates

| ID | Due | Deliverable | Gate |
|---|---|---|---|
| M0 | Oct 27 | Existing-repo audit and baseline | Git SHA, service inventory, exact smoke-test evidence, no secrets, approved architecture |
| M1 | Oct 28 | Deterministic digital twin | Energy balance and state-of-charge tests pass |
| M2 | Oct 29 | Muse Spark tool-using agent | Typed tool-call validation, offline tests, authorized live request |
| M3 | Oct 30–31 | Forecast and optimizer | Constraints hold and baseline comparison is reproducible |
| M4 | Nov 1 | Safety and perception | Approval flow, complete audit, SAM segmentation optional |
| M5 | Nov 2 | Dashboard and deployment | End-to-end incident demonstration reachable in staging |
| M6 | Nov 3–4 | Demonstration and submission | Public-facing artifacts, testing evidence, complete submission |

**Advance rule:** implementation → automated tests → manual review → documentation → clean scoped commit → owner approval. Never infer approval.
