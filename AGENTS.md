# Agent guidance

Read `docs/hackathon/AGENT_PROMPT.md`, `docs/hackathon/PROJECT_BRIEF.md`, `docs/hackathon/MILESTONES.md`, and `docs/hackathon/ARCHITECTURE.md` first. Only work on the currently approved milestone. In M0, verify the local health endpoint, typed contracts, docs and GitHub CI; do not implement M1. Never read or expose actual `.env` secrets or `cred.json`. Require operator approval before advancing.

Hackathon-new code lives in `src/eden/sentinel/`; everything else under `src/eden/` is pre-existing EDEN. Keep that boundary and record any reuse in `docs/hackathon/BASELINE.md`.
